## Student management System using OOP Project for beginner
A lightweight, console-based Student Management System built in Java. This application demonstrates core Object-Oriented Programming (OOP) concepts and dynamic data management using the Java Collections Framework.
##  Features
* **Add Student**: Insert new records with an ID, name, age, and grade score.
* **View Records**: Display a formatted list of all stored student profiles.
* **Search**:  search student by ID.
* **Delete**: Safely remove student data from the system using their unique ID.
* **Memory Management**: Utilizes `ArrayList` for dynamic, resizable data storage during execution.
